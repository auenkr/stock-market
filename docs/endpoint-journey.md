# Endpoint user journey

Generated by `pnpm docs:generate`. Public documentation is organized as Search → Company overview → Finance. Internal is shown in served documentation only when `ENVIRONMENT=dev`; this repository guide includes it for development. Market-price history remains excluded.

Aliases stay beside their canonical endpoint in the API reference. Free/Paid labels describe access within each category.

## 1. Search

Search by company name or browse the paginated company list. Both return the original company URL path as symbol.

| Use | Endpoint | Tier | Coverage |
| --- | --- | --- | --- |
| Search companies by name | `/v1/company-search` | free | legacy |
| List companies | `/v1/list-of-company` | free | legacy |

## Company identifiers

Search, company listing, and upcoming IPOs return `symbol`, containing the unchanged company URL path. All company endpoints use this identifier, including older company-data/extraction, ownership, dividends and corporate actions. Company overview and Finance accept only this query parameter, for example `/v1/profit-loss?symbol=%2Fcompany%2FRELIANCE%2Fconsolidated%2F`. No ticker extraction is needed. The URL selects standalone or consolidated data; period, statement type/code, ratio type, group, and page filters are not accepted here. Shareholding pattern and distribution default to quarterly. Company corporate actions accept optional `action=split|bonus|rights|dividend`; omit it for all actions. Personal `/api/v1` routes have `/v1` aliases. See [API compatibility](api-compatibility.md) for units, query filters, and calendar/IPO sources.
